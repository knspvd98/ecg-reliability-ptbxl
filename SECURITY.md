# Security policy

## Scope

This repository contains research software. It is not a medical device and is
not intended for diagnosis, treatment, triage, or clinical deployment.

## Reporting a vulnerability

Please report security issues privately through the contact information on the
maintainer's GitHub profile. Do not include credentials, patient information,
private datasets, or access tokens in a public issue.

## Data handling

- PTB-XL and external datasets remain outside Git.
- Generated signals, checkpoints, predictions, and reports are ignored.
- The pipeline expects de-identified public research datasets only.
- No credential is required by the codebase.
